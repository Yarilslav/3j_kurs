# User Flows

## Booking flow
1. User opens the Home page.
2. User goes to Booking.
3. User chooses date/time and places.
4. User enters guest contact details or uses an authenticated session.
5. User submits reservation.
6. UI shows confirmation state on the Booking page.

## Product order flow
1. User opens the Home page.
2. User goes to the Catalog.
3. User opens a product details page.
4. User fills the order form.
5. User submits the order.
6. UI shows confirmation state on the Product page.
